# Naama Melzer — Video Editing Portfolio

Static portfolio for https://www.naamamelzer.studio. The active experience focuses on Video Editing. Art Design and Costume Design pages are retained but hidden from the navigation and excluded from indexing.

The contact form uses FormSubmit's free AJAX endpoint. The destination mailbox must be activated once by following the verification link. See [SETUP-CHECKLIST.md](SETUP-CHECKLIST.md).

Analytics is prepared for Cloudflare Web Analytics. Add the site-specific beacon snippet to the three active pages using the checklist. Cloudflare Web Analytics is free and does not require changing DNS or proxying the domain.
